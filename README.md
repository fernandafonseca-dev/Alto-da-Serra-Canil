Alto da Serra Canil
Website institucional desenvolvido para o Alto da Serra Canil, com o objetivo de apresentar a estrutura, os serviços e as informações do estabelecimento, além de facilitar o contato com pessoas interessadas na compra de filhotes e na hospedagem de cães.

O site reúne informações sobre as raças disponíveis, venda de filhotes, hospedagem e estrutura do resort canino, com páginas dedicadas à galeria de imagens, certificados e contato.
Funcionalidades
- Página inicial: apresentação do Alto da Serra Canil e acesso às principais áreas do site.
- Raças: catálogo de raças, com páginas individuais para French Bulldog, Golden Retriever, Labrador, Pastor Alemão, Poodle e Shih Tzu.
- Venda de filhotes: informações sobre o processo de compra e os filhotes.
- Hospedagem e resort canino: apresentação dos serviços, acomodações e instalações.
- Galeria: exibição de imagens dos espaços e da estrutura.
- Certificados: página dedicada a certificados e reconhecimentos.
- Contato: formulário de contato e canais de comunicação, incluindo telefone, e-mail e WhatsApp.
- Elementos interativos: menu responsivo, filtros de raças, abas, modais, animações ao rolar a página e opção de tema escuro.
Tecnologias utilizadas
- HTML5 — estruturação das páginas.
- CSS3 — estilos, identidade visual e responsividade.
- JavaScript — interações, filtros, navegação, validações e efeitos visuais.
O projeto utiliza arquivos locais, sem necessidade de ferramentas de build para sua execução.

Como executar localmente
Como o projeto é desenvolvido com HTML, CSS e JavaScript, não é necessário instalar dependências.
1. Faça o download ou clone este repositório.
2. Abra a pasta do projeto.
3. Abra o arquivo index.html em um navegador.
Para uma experiência melhor durante o desenvolvimento, você também pode abrir a pasta no Visual Studio Code e utilizar a extensão Live Server.
Observação sobre o formulário
Atualmente, o formulário da página de contato realiza validações no navegador e exibe uma mensagem simulada de sucesso. Ele não está conectado a um serviço de envio de e-mails ou a um backend; portanto, o preenchimento não envia os dados para uma caixa de entrada.
